# Hiver SDE Intern — AI Support Agent for AppleSupport

A classifier + RAG reply generator + escalation decider for AppleSupport Twitter conversations.

## Quick Start (Under 15 Minutes)

### 1. Prerequisites

- Python 3.11
- Groq API key (free tier — https://console.groq.com)
- Google Gemini API key (free tier — https://aistudio.google.com/app/apikey)
- Kaggle API token (free — https://www.kaggle.com/settings/account)

### 2. Install

```bash
pip install -r requirements.txt
pip install google-genai
